# Brand shortlist

These are working-name ideas for the platform. The code defaults to **GuidePaw Beta** via environment variables so the visible brand can change later without a deeper refactor.

## Strong options
1. **GuidePaw**
   - friendly, clear, service-dog-adjacent
2. **TaskPatch**
   - nod to tasks + vest patches + field use
3. **HandlerGrid**
   - more operational / team oriented
4. **WorkingTeam**
   - broad enough for collaboration and trainers
5. **SteadyCue**
   - good fit for training + reliability + public access work

## My recommendation
**GuidePaw** is the best short-term beta name.
It is easy to say, easy to remember, and broad enough to cover:
- service dog logging
- health records
- training
- collaboration
- future Android/iPhone apps

Before public launch, do a proper trademark and domain check.
