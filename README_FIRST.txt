GuidePaw current PostgreSQL package

Recommended zip name:
- gpb3.zip

Included in this bundle:
- current app code
- PostgreSQL schema only
- updated docs
- Ubuntu migration guide
- Render beta guide
- phone sandbox guide

Immediate first steps on a new machine:
1. Create PostgreSQL database and user.
2. Import `latest postgres sql.txt`.
3. Start the app with PHP built-in server first.
4. Verify register, dogs, quick log, history, reports, and backup.
5. Only then move behind Nginx/PHP-FPM or deploy to Render.
